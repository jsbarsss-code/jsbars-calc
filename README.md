# 우리집 열쇠가 내 손에 — 집 매매 전략 짜기

내 연봉·현금으로 어디까지 집을 노려볼 수 있는지, 살고 싶은 역·단지 주변 후보 중 예산 안 단지는 어디인지 계산하는 페이지입니다. 입력값은 브라우저 안에서만 계산하고 저장하지 않습니다.
