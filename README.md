# 내 연봉 집 계산기

사고 싶은 집 가격과 내 연봉·현금만 넣으면 살 수 있는지, 모자란 금액, 필요한 연봉을 계산하는 정적 페이지입니다. 입력값은 브라우저 안에서만 계산하고 어디에도 저장하지 않습니다.

- 주소 파라미터로 값을 채워 열 수 있습니다: `?name=단지명&price=52000&region=reg|capital|local&salary=6000&cash=25000&first=1` (금액은 만원 단위)
- 참고용 추정치입니다. 실제 대출 한도와 금리는 은행 심사로 정해집니다.
- 만든 곳: [jsbars 블로그](https://blog.naver.com/jsbars)
